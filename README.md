## 💻 Running Locally

To run and preview the portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/keerthi0079/portfolio.git
   cd portfolio
   ```

2. **Start the local server:**
   - On Windows: Double-click **`start-server.bat`** OR run:
     ```bash
     node server.js
     ```
   - Alternatively, open with VS Code's **Live Server** extension.

3. **View in browser:**
   Open [http://localhost:3000](http://localhost:3000) in your web browser.
